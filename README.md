# Aqua Reminder

**Drink Water. Stay Hydrated. Feel Better.**

A premium, offline-first Android hydration tracker built with Flutter and Material 3.

## Features

- 💧 Water tracking with quick-add buttons, custom amounts, and drink types
- 🎯 Customisable daily goal with historical accuracy
- 🔔 Local reminder notifications with quiet hours and pause-after-goal
- 📊 Weekly statistics with real database-driven charts
- 🏆 Achievements and streaks (First Drop, 3-Day, Week Warrior, Hero, King)
- 🌗 Light / dark / system theme
- 📤 CSV export of all records
- 📴 Fully offline — no account, no backend, no tracking

## Tech

Flutter • Provider • SQLite (sqflite) • flutter_local_notifications • fl_chart • SharedPreferences
